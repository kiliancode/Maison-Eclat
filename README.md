# Maison-Eclat
Site vitrine dédié à Maison Éclat, un café artisanal fictif situé à Clermont-Ferrand : présentation de son univers, de ses cafés, de ses pâtisseries, de son histoire et de son ambiance.

Projet personnel réalisé pour apprendre à créer et publier un site web de A à Z (code, GitHub, hébergement, SEO et référencement). Site web fictif créé dans un but d'apprentissage.
